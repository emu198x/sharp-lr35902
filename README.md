# sharp-lr35902

The Sharp LR35902 (SM83), the Game Boy's CPU core, at machine-cycle granularity.

| Crate | Registry |
|---|---|
| [`emu198x-sharp-lr35902`](crates/emu198x-sharp-lr35902) | [crates.io](https://crates.io/crates/emu198x-sharp-lr35902) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Game Boy and Game Boy Color.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
